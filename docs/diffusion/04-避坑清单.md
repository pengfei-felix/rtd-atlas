# Diffusion 避坑清单

| 坑 | 现场后果 | 正确做法 |
|---|---|---|
| 把装载率当主指标 | 窗口内硬等，Q-time 爆 | 装载率只做观测指标，主指标看有效产出 + 窗口风险 |
| 只按 recipe code 组炉 | 可同炉关系过窄或过宽 | 建 recipe family / campaign family |
| 清洗后才开始凑批 | 已进入危险窗口，选择空间变小 | 清洗前做组炉预测，清洗节奏与开炉联动 |
| 炉管空闲才找 Boat | 辅助资源不到位造成空等 | yellow 阶段提前锁定 Boat / Quartzware |
| 忽略出炉波峰 | 下游 clean / metrology 被打穿 | 开炉前预测 projected outflow |
| Campaign 不设打断条件 | Hot Lot 或 Q-time Lot 被饿死 | 设置最大 campaign 时长和红/黄区打断规则 |
| 半炉救火不复盘 | 长期吞吐下降但没人归因 | 统计 half-batch ratio 和 red-start count |
| PM / clean 不进能力扣减 | APS 产能假设偏乐观 | 用 effective capacity 回灌 APS |

## 最小上线检查

1. recipe family 表是否经工艺确认；
2. 清洗前/后 Q-time 起点是否一致；
3. Boat / Quartzware 状态是否实时可见；
4. SRB 等待阈值是否来自历史到达分布；
5. 出炉波峰是否能在回放中复现；
6. 半炉开是否有 reason code；
7. 规则上线前是否跑过历史回放。
