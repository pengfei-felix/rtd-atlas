# Diffusion 区派工档案

!!! note "状态：骨架待填"

## 与 Litho 的结构差异（先定性）

**这是一个批量（batch）问题，不是单片刻度问题。** 派工的核心决策不是「哪个 Lot 上哪台机」，而是「哪些 Lot 拼成一炉」。组炉决策一旦做错，代价是几小时到十几小时的炉管时间被浪费。

## 预期约束清单

| 约束 | 本区表现 | 待你核实 |
|---|---|---|
| 批量设备 | 卧式/立式炉，单炉装载量大，lot 需凑满 | 单炉片数与最小装载 |
| 组批规则 | 同 recipe + 同温度曲线才能同炉；可混批的条件需明确 | 混批规则 |
| 长驻留 | 单道工序耗时数小时起，在制品占用高 | 典型工艺时长 |
| 序列相关整定 | 升降温极慢，换温度曲线的代价远大于换 recipe | 升降温曲线时长 |
| Q-time 前窗 | 清洗后到进炉的时间窗，超时需重洗 | 窗口长度 |
| Q-time 后窗 | 出炉后到下一工序的窗口 | 窗口长度 |
| 机台专属性 | 关键层固定炉管，控制膜厚均匀性 | 锁定范围 |
| 辅助资源 | 石英件/舟（boat）寿命与更换周期 | 是否计入产能 |

!!! tip "本区最容易踩的坑"
    把组炉当成派工的前置步骤而不是同一层决策。实际生产中「先到先组」会把大批同 recipe 的 Lot 拆碎，导致后续炉次装载率上不去——组炉和派工必须一起算。
