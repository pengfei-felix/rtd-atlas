# 区域派工档案 · 总览

五个区，五套约束结构。不能拿一套派工逻辑套全场——这是本文档集的核心立场。

## 横向对比

| 维度 | Litho 光刻 | Etch 刻蚀 | Diffusion 扩散 | Implant 注入 | CMP 研磨 |
|---|---|---|---|---|---|
| 决策粒度 | Lot → 机台 | Lot → **chamber** | **组炉** + 机台 | 批 → 机台 | Lot → 机台 |
| 辅助资源 | **Reticle + Pod**（唯一、需搬送） | 腔体资质 / matching | 舟具、石英件 | 气体、靶材 | **Pad**（连续退化） |
| Setup 主因 | 换罩 + 温层升降温 | 换 recipe + chamber clean | **升降温曲线** | **换气/换能量** | pad dressing |
| 批量性 | 单片 | 单片 | **强批量** | **强批量** | 单片 |
| Q-time 压力 | 中（多段嵌套） | **高**（后段腐蚀） | 高（前后双窗） | 高（退火窗口） | 中 |
| 闭环反馈 | 弱（套刻量测） | 中（CD 量测） | 弱 | 弱 | **强**（run-to-run） |
| 专属性强度 | **强**（关键层锁机） | 强 | 强 | 中 | 弱 |

## 读一个区的方法

不管是哪个区，都按同一个顺序拆，**顺序不能乱**：

1. **先数辅助资源**。除了机台，还有什么东西是「同一时刻只能被一处使用」的？Litho 是 Reticle/Pod，CMP 是 Pad，Etch 是 chamber 资质。这一层最容易被漏，也最容易造成「计划可行、现场做不到」。
2. **再定决策粒度**。Lot 级、chamber 级还是 batch 级？粒度错了，后面所有优化都白做。
3. **然后区分 setup 的两类**。序列相关（换线顺序有讲究）vs 固定（换一次就是固定代价），两者在优化里的处理方式完全不同。
4. **最后看 Q-time 的嵌套层数**。单窗口好处理，多窗口串联会互相锁死。
5. **闭环反馈单独建模**。CMP 这种「上一批结果决定下一批参数」的，派工和工艺控制不能分开算。
