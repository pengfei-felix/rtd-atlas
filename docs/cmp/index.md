## 与 Litho 的结构差异（先定性）

**这是唯一有强闭环反馈的区。** 前道的量测结果直接决定下一批的加工参数（研磨时间），派工不只是排队，还要决定「派给哪台机、用哪套参数」。研磨垫（pad）的磨损状态让同一台机在不同时刻表现不同——这是一个会随时间漂移的资源。

## 预期约束清单

| 约束 | 本区表现 | 待你核实 |
|---|---|---|
| Pad 寿命 | 研磨垫磨损影响去除率，需定期 dressing / 更换 | 寿命计数口径 |
| 参数漂移 | 同 recipe 在不同 pad 年龄下需调加工时间 | 漂移幅度 |
| 量测闭环 | 前批厚度结果反馈到后批参数（run-to-run 控制） | 控制策略 |
| Slurry 供应 | 研磨液种类与供给可能成为隐性约束 | 是否进模型 |
| 机台专属性 | 相对宽松，但 head/platen 级有匹配要求 | 匹配要求 |
| Q-time | 研磨后到下一层的等待窗口（氧化/污染） | 窗口长度 |
| 清洁与交叉污染 | 铜/非铜不能混跑 | 隔离规则 |
