# 约束四类 · 强制图例

<div class="keyline" markdown>

**全库所有约束必须归到这四类之一。** 这不只是分类习惯——没标类型，就没法回答"全厂哪些约束属于辅助资源"这种决定投人方向的问题。

</div>

## 四类资源

<div class="grid cards" markdown>

-   :material-cog-transfer:{ .lg .middle } __① 主资源__

    ---

    执行加工的设备或设备子单元。

    **判据**：能独立排产的最小物理单元。

    机台 · chamber · platen · 炉管

    <span class="badge badge--new">核心</span>

-   :material-package-variant-closed:{ .lg .middle } __② 辅助资源__

    ---

    加工必需，但不能同时被两处使用。

    **判据**：它不在位，机台就只能空转。

    Reticle · Pod · Pad · Boat · 靶材

    <span class="badge badge--new">最易漏</span>

-   :material-timer-sand:{ .lg .middle } __③ 时间窗资源__

    ---

    只能在某个时间区间内消耗的机会。

    **判据**：错过窗口，前面的加工全部作废或需返工。

    Q-time · Timelink · Hold time

    <span class="badge badge--new">跨区</span>

-   :material-account-hard-hat:{ .lg .middle } __④ 人力 / 物料__

    ---

    受班次、库存、供应限制的投入。

    **判据**：缺它不宕机，但会降速或停线。

    工程师支持 · 特种气体 · Slurry

    <span class="badge badge--new">常被忽略</span>

</div>

## 建模陷阱

四类各有各的坑，坑的共同点都是**把连续或受限的东西简化成布尔量**。

| 类型 | 正确建模 | 错误建模 | 后果 |
|---|---|---|---|
| 主资源 | 带资质矩阵、非对称资格 | 同型号视为等效 | 加工时间估计偏差数倍 |
| 辅助资源 | 带位置、容量上限、搬运时延、寿命计数 | 只做"可用 / 不可用" | 排出物理上做不到的计划 |
| 时间窗 | 带前后双窗、嵌套校验 | 只校验单点 | 单段合规、串联超时 |
| 人力物料 | 带库存水位、补货周期 | 视为无限 | 计划可行、现场停线 |

!!! danger "最贵的一个错误"
    把 **Reticle 建成布尔量**。正确建模是带位置、带容量上限、带搬运时延、带寿命计数的受限资源。前者会让 RTD 排出大量"看起来可行、实际做不到"的派工——这是光刻区白空间的第一大来源。

## 全区域对照

同一类资源在不同区的表现形式完全不同。这张表是横向对照的入口。

| 区域 | ① 主资源 | ② 辅助资源 | ③ 时间窗 | ④ 人力物料 |
|---|---|---|---|---|
| **Litho** | 光刻机 | **Reticle + Pod** | 曝光后到显影 | 掩模检查能力 |
| **Etch** | chamber | 腔体资质、matching 状态 | 刻蚀后到去胶 | 特种气体 |
| **Diffusion** | 炉管 | 舟具、石英件 | 清洗后进炉 / 出炉后 | 石英件更换 |
| **Implant** | 注入机 | 气体种类、靶材 | 注入后到退火 | 专用气体 |
| **TF** | 沉积腔体 | **靶材 / 前驱体（消耗）** | 沉积后到下一道（native oxide） | 靶材交期 |
| **CMP** | 研磨机 / platen | **Pad（连续退化）** | 研磨后到下一层 | Slurry |
| **Clean** | 清洗槽 / 单片设备 | **Bath（化学消耗）** | **清洗出槽 → 下一道（走廊起点）** | 药液、超纯水 |
| **Metrology** | 量测机台 | 校准片、标准片 | 量测结果反馈时限 | 校准能力 |
| **Sorter** | Sorter / Stocker | **载具（FOUP/Cassette）** | 时效性弱 | 载具清洗能力 |

**四类资源在九区的分布有两个规律：**

1. **② 辅助资源越强的区，规则越难配。** Litho、TF、CMP、Clean、Sorter 的辅助资源都是独占或退化型，它们占了全厂「计划可行、现场做不到」问题的大头。
2. **③ 时间窗的起点集中在 Clean。** 全厂大部分 Q-time 走廊从清洗出槽开始计时，这是 Clean 在规则体系里权重远超其产能占比的原因。

## 怎么用这套图例

1. **写约束时先标类。** 每条约束开头加一个类型标签，例如"② 辅助资源 · Reticle 唯一性"。
2. **按类横向检索。** 想知道全厂哪些约束属于辅助资源，直接搜"② 辅助资源"，得到跨区域的全集。
3. **按类决定建模方式。** 同类型的约束，建模方法基本通用——这是四类划分的真正价值。

## 与约束模型的关系

四类资源是**分类法**，[约束模型](../method/constraints.md) 是**怎么把它们变成可计算的东西**。先分类，再建模，顺序不能反。
