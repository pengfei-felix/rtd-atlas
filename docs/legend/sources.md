# 参考来源

<div class="keyline" markdown>

**本页记录可公开引用的来源类型。** 这个项目不放内部产线数据、报价、未公开 POC 细节；涉及公开案例和改善幅度时，只采用公开资料或明确标注为经验判断。

</div>

## 来源类型

| 类型 | 可用范围 | 注意 |
|---|---|---|
| 公开论文 / 会议论文 | 调度模型、算法、案例量级 | 不直接当作本厂收益承诺 |
| 公开专利 | 约束建模、资源管理思路 | 专利方案不等于产品能力 |
| 公开产业材料 | 产品边界、公开案例、术语 | 避免照搬宣传语 |
| 教材 / 专著 | TOC、瓶颈、投料、组批、智能调度 | 注意年代与工程实践差异 |
| 个人工程分析 | 约束拆解、方法论抽象 | 必须避免内部敏感信息 |

## 本项目常用公开知识锚点

| 主题 | 来源方向 |

## 引用口径

公开案例里的改善数字，如“利用率 +1%~2%”“吞吐 +2%~9.4%”“Reticle Move -5%”“Q-time -4%”，只能作为量级参考。

不能写成：

> 上线 RTD 后必然提升吞吐 5%。

建议写成：

> 公开案例显示同类问题有几个百分点量级的改善空间；正式项目应以本厂历史基线、产品 mix、设备状态和验证窗口为准。

## 禁止进入仓库的内容

- 具体公司的产能、良率、客户信息；
- 报价、合同、未公开 RFP / POC 细节；
- 内部会议纪要中的敏感决策；
- 能反推出工艺能力、经营状态或采购策略的数据；
- 未脱敏的截图、表格和系统日志。
