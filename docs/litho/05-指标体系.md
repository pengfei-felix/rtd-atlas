# 指标体系

**第一原则：指标会互相打架，必须显式选主指标。** TWT / OTD / MCT / UOB / Makespan 不可能同时最优。典型实例：用优化算法改善瓶颈后，TWT、OTD、MCT 显著优于 FIFO/CR/EDD，但**瓶颈设备利用率 UOB 改善不明显——要提高瓶颈利用率必须有投料策略配合**。

| 类别 | 指标 | 说明 | 建议目标形态 |
|---|---|---|---|
| **主产能** | Litho OEE / 利用率 | 唯一能对齐财务的指标 | 主目标或硬约束 |
| | Litho Wafer Out / 班 | 直接产出 | 主目标 |
| | White Space 时长及归因 | **必须按原因拆分**：等罩 / 等料 / 等人 / 换罩 / 宕机 / 等检查 | 归因后分项攻坚 |
| **周期时间** | 分优先级 CT（P1/P2/P3 分层） | **总平均会掩盖 Hot Lot 吃掉常规批的问题** | 分层考核 |
| | Litho Queue Time | 队列等待 | 下降 |
| | X-Factor（CT / 理论加工时间） | 跨产品可比 | 下降 |
| **光罩** | Reticle Move 次数 / 班 | 与吞吐权衡，用交换比定权重 | 约束项 |
| | Reticle Wait Idle Time | **机台因等罩空转的时长 —— Litho 最该盯的单一指标** | 趋零 |
| | Reticle 检查导致的机台停工时长 | 寿命管理质量 | 趋零 |
| | Inhibit Limit 命中次数 | 硬卡控被触发 | **必须为 0** |
| **约束合规** | Q-time / Timelink 违规次数 | 良率风险直接暴露 | 趋零 |
| | Dedication 命中率 | 关键层同机达成率 | >99% |
| | 重工回原机台命中率 | — | 高 |
| **均衡** | 机群内机台负载标准差 | CAPPA 的优化目标 | 下降 |
| | 层间 WIP 分布（按光刻层分桶） | 重入流是否失衡；LCONWIP 的管控对象 | 均衡 |
| **系统健康** | **人工干预（Manual Override）率** | **最被忽视的核心指标；>15% 基本等于 RTD 失效** | <5% |
| | 派工决策延迟 P99 | 毫秒级要求，须在真实产能下压测 | 达标 |
| | Rule 总数与月增量 | 规则库膨胀预警 | 监控 |
| | 计划执行偏差 \|L\| 分布 | RTS-RTD 协同质量 | 可控波动 |

> **关于 |L| 的正确期望**：`L = max(0, Te − Ta) − max(0, Ta − Te)`（Te 预计开始、Ta 实际开始）。**真正好的 RTD 不是让 L = 0，而是让 L 在可接受范围内小幅波动**——既有弹性，又不失控。L 恒为 0 说明 RTD 变成了传声筒。
