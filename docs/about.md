# 关于《RTD 派工图志》

这是一份半导体 Fab 实时派工（RTD / APS）的开源工程图志。它按区域和专题组织内容，用同一套体例记录约束、问题、派工策略、数据字段与验证指标。

名字取“图志”而不是“百科”，因为这里不追求收全所有术语，而是追求把派工现场画清楚：**东西怎么流、哪里会堵、RTD 能做什么、做完怎么验证。**

## 内容边界

**包含**：

- 公开文献、专利、教材和公开案例中的调度方法；
- 行业共识的约束建模、瓶颈、投料、组批、指标方法；
- 面向工程落地的个人分析：字段、规则、日志、验证口径。

**不包含**：

- 具体公司的产线数据、产能、良率、客户信息；
- 供应商报价、合同、RFP、POC 细节；
- 能反推出某家公司经营状态、工艺能力或采购策略的内部信息。

文中所有公开改善数字都只能作为量级参考，不能作为项目承诺值。落地前必须以本厂基线、产品 mix、设备状态和验证窗口为准。

## 为什么按区域切

派工问题在不同区域的结构差异极大：

- Litho 是 Lot、Reticle / Pod、机台状态耦合；
- Etch 要下沉到 chamber；
- Diffusion 是组炉和温区问题；
- Implant 是 setup family 和污染隔离问题；
- CMP 是 Pad 退化和 Run-to-Run 反馈问题。

用一套通用逻辑讲，会得到正确但无用的结论。按区域切，才能看到真正的约束结构。

## 为什么还要跨幅专题

区域页讲“这个区怎么派”，跨幅专题讲“区与区之间怎么互相引爆”。

目前四条主线是：

- Q-time 走廊；
- 辅助资源流转；
- 重入流路径；
- 指标冲突链。

这些专题决定了局部最优能不能变成全厂收益。


构建通过后再提交。
