# 关于《RTD 派工图志》

一份半导体 Fab 实时派工（RTD / APS）的个人图志。按区域横向积累，每个区一张图，用同一套体例记录约束、问题、解法与指标。

名字取「图志」而非「知识库」：atlas 的本义是把多张地图装订成册，区域是一个个分幅，体例是让每幅图都能互相参照的那套规矩。

## 内容边界

**包含**：公开文献、专利、厂商公开资料的分析与整理；行业共识的方法论；个人对现场问题的结构化理解。

**不包含**：任何具体公司的产线数据、产能数字、良率、客户信息、供应商报价。文中出现的改善幅度均来自公开资料，且已标注其基线局限。

## 为什么按区域切

派工问题在不同区域的结构差异极大——光刻区是「三体问题」（Lot / Reticle / 机台状态耦合），炉管是组炉问题，注入是换线成本主导，CMP 是闭环反馈问题。用一套通用逻辑讲，只会得到正确但无用的结论。
