# 腔体 Dedication 与靶材寿命

<div class="keyline" markdown>

**Dedication 决定"谁能做"，靶材寿命决定"现在做得对不对"。** 两条都满足才有资格接这张工单，缺一条就是计划可行、现场做不到。

</div>

## Dedication 的三层

| 层 | 来源 | 强制力 | 谁维护 |
|---|---|---|---|
| **工艺锁定** | 关键层的工艺窗口只容得下特定腔体 | 硬，不可覆盖 | 工艺 owner |
| **Matching 分组** | 腔体间膜厚/均匀性差异在容差外 | 硬，但可通过 requal 解除 | 设备 + 工艺 |
| **质量偏好** | 历史表现更好，但非必须 | 软，加权 | 区域 owner |

三层混在一起配，是最常见的错误：把质量偏好升级成硬约束，产能被自己锁死；把 matching 当成偏好，关键层跑到不匹配的腔体上。

### 怎么判断该配哪一层

```text
如果换腔体会导致这一层超出工艺窗口 → 工艺锁定（硬）
如果换腔体后需要重新 qual 才能用     → matching 分组（硬）
如果换腔体会让良率略降但仍合格       → 质量偏好（软）
```

判断依据不是"工程师觉得哪台好"，是**换腔体后的实测差异有没有超出容差**。

## 靶材寿命模型

靶材不是耗材，是**退化型资源**：末期不会突然坏，而是颗粒和膜厚稳定性逐步变差。

| 阶段 | 剩余量 | 表现 | 派工处理 |
|---|---|---|---|
| Break-in | 100% → 95% | 表面状态未稳定，膜厚偏 | 禁止关键层 |
| Stable | 95% → 30% | 稳定 | 正常派工 |
| Warning | 30% → 10% | 颗粒开始上升 | 限制关键层 |
| End-of-life | < 10% | 不稳定 | 只跑非关键层 / dummy |

用累积什么计量，取决于机台：

| 机台类型 | 常用计量 | 注意 |
|---|---|---|
| PVD | 累积 kWh 或片数 | kWh 更准，不同 recipe 功率不同 |
| CVD | 前驱体流量 / 液位 | 换瓶后需重新稳定 |
| ALD | 脉冲计数 | 前驱体消耗与循环数线性 |

**只用片数计量会低估高功率 recipe 的消耗。** 同一台机跑高功率和低功率 recipe，片数一样但靶材磨损差很多。有 kWh 数据就用 kWh。

## Segment 划分的经验值

30% / 10% 不是通用值，要按靶材类型和工艺标定：

| 参考 | Warning 起点 | EOL |
|---|---|---|
| 常规金属靶（Al/Ti/TiN） | 25%~30% | 5%~10% |
| 贵金属靶（Au/Pt） | 可放宽，成本驱动 | 3%~5% |
| 反应溅射（靶面中毒风险） | 提前，40% 左右 | 10% |

反应溅射要提前，因为靶面状态变化是非线性的，末期突然漂移的情况比金属靶多。

## 状态字段

| 字段 | 说明 |
|---|---|
| `chamber_id` | 腔体唯一标识 |
| `dedication_class` | 工艺锁定 / matching 组 / 软偏好 |
| `matching_group` | 所属 matching 组，同组内可互换 |
| `qual_status` | 已 qual 的 recipe 列表 |
| `target_remaining` | 剩余量，带计量单位 |
| `target_segment` | break_in / stable / warning / eol |
| `pm_due` | 下次 PM 时刻 |
| `seasoning_state` | 是否处于 seasoning 期 |

`target_segment` 建议由系统算，不要让现场手填。手填的分段一定会滞后——靶材快到期了但没人更新状态，是这类问题的典型来源。

## 组合判定

单个条件都满足，组合起来仍需判定：

| Dedication | 靶材分段 | 判定 |
|---|---|---|
| 工艺锁定 | stable | 可派 |
| 工艺锁定 | warning | 可派，但记录，且优先安排正常批消化 |
| 工艺锁定 | **eol** | **冲突**：既锁死又不能用 → 触发 requal 或换靶 |
| matching 组内 | stable | 组内任选，按利用率均衡 |
| 软偏好 | 任意 | 加权，可被 P1/P2 覆盖 |

「工艺锁定 + EOL」这一格是真实存在的死锁：唯一能跑这个层的腔体靶材到寿命了，换靶要停机，不换靶关键层就停摆。**这必须在计划层解决，不能靠派工绕。**

## 典型问题

### 问题 1：软偏好被配成硬约束

| 项 | 内容 |
|---|---|
| 现象 | 关键层只有一台机在做，其余腔体空转 |
| 根因 | dedication_class 配错层级 |
| 解法 | 按"换腔体是否超容差"重新定级 |
| 指标 | dedication blocked count、腔体利用率离散度 |

### 问题 2：靶材状态靠人填，长期滞后

| 项 | 内容 |
|---|---|
| 现象 | 系统显示 stable，实际靶材已到末期 |
| 根因 | 状态手工维护，无自动计量 |
| 解法 | 从机台日志自动累加，状态由系统计算 |
| 指标 | target state lag、末期膜厚偏差 |

### 问题 3：matching 组过期没重算

| 项 | 内容 |
|---|---|
| 现象 | 曾经匹配的腔体，PM 后不再匹配但仍在同一组 |
| 根因 | matching 组没有失效机制 |
| 解法 | PM 或部件更换后强制 requal，组状态重置 |
| 指标 | post-PM matching deviation |

## 一条实操建议

把 dedication 和靶材状态做成**联合可用性矩阵**，而不是两个独立过滤器。派工时先查矩阵，再看其他约束。

```text
chamber_availability = f(dedication_class, matching_group,
                         qual_status, target_segment,
                         pm_due, seasoning_state)
```

这个函数的输出不是布尔值，是**可用等级**：

| 等级 | 含义 |
|---|---|
| A | 完全可用，关键层可派 |
| B | 可用，仅非关键层 |
| C | 仅 dummy / seasoning |
| D | 不可用 |

按等级过滤比按布尔过滤灵活得多，也能解释"为什么这台机没被选中"。
