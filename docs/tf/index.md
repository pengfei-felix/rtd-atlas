# TF 薄膜区派工档案

<div class="keyline" markdown>

**TF 是"长多少"比"谁来做"更重要的区。** 刻蚀看的是把材料拿掉多少，薄膜看的是长了多少——厚度、均匀性、应力三项一旦偏了，返工代价是整层剥离重做。所以 TF 的派工不是找空闲机台，是找"能把这一层做对"的腔体。

</div>

## 核心结论

1. **决策粒度是 chamber，不是 tool。** 一台 cluster tool 里各腔体的靶材年龄、PM 记录、matching 状态都不同。
2. **靶材是消耗型资源，不是耗材。** 它的剩余寿命直接影响膜厚稳定性和颗粒水平，要按状态段限制可用范围。
3. **关键层 dedication 很强。** 某些层锁死特定腔体，不是偏好，是不许换。
4. **膜厚与应力是双约束。** 只盯厚度，应力漂了会在后续光刻和键合上爆出来。
5. **返工代价高于等机。** 镀错了要 strip 重做，中间可能破坏已完成的层。

<div class="rtd-strip" markdown>

<span>决策粒度</span> Lot → Tool → Chamber → Target state  
<span>核心矛盾</span> 腔体专属 vs 产能 vs 膜厚稳定

</div>

## 与其他区的结构差异

| 维度 | Etch | TF | 差异要点 |
|---|---|---|---|
| 加工方向 | 减材 | 增材 | 薄膜多一层就不能回退 |
| 主消耗资源 | 无（气体除外） | **靶材 / 前驱体** | 靶材寿命直接进派工约束 |
| 关键输出 | CD / profile | **厚度 / 均匀性 / 应力** | 三项都是连续量，不是合格/不合格 |
| 反馈强度 | 中 | **中偏强** | 膜厚量测可反哺参数 |
| 返工代价 | 中（重刻） | **高（剥离重镀）** | 可能伤及底层 |

TF 和 Etch 的粒度相同（都是 chamber），但资源结构不同：Etch 的 chamber 约束来自"状态"（seasoning、PM），TF 的 chamber 约束来自"状态 + 消耗品剩余量"。

## 六类约束结构

### 1. Chamber Dedication

| 类型 | 表现 | 派工处理 |
|---|---|---|
| 关键层锁定 | 某些层只能跑指定腔体 | 硬约束，P0 |
| 产品族限定 | 某产品只在某组腔体加工 | 硬约束 |
| 软性偏好 | 质量更稳但非必须 | 加权，可被更高优先级覆盖 |

dedication 的来源通常是 matching 结果。**软性偏好和硬约束必须分开配**，否则产能会被自己锁死。

### 2. 靶材与消耗品

| 资源 | 计量方式 | 派工影响 |
|---|---|---|
| PVD 靶材 | 累积 kWh 或片数 | 末期颗粒升高，限制关键层 |
| CVD 前驱体 | 液位 / 累积流量 | 低水位触发限制 |
| ALD 前驱体 | 瓶压 / 脉冲计数 | 换瓶需重新稳定 |
| Shower head / 部件 | 累积膜厚 | 影响均匀性，需 PM |

靶材末期不是"不能用"，是"不能用在关键层"。这个区分决定了产能和良率的平衡点。

### 3. PM 与 Seasoning

薄膜的 seasoning 比刻蚀更敏感——新部件或新靶材的前若干片膜厚会偏。

| 状态 | 处理 |
|---|---|
| 刚 PM 完 | seasoning 批，禁止关键层 |
| Seasoning 中 | 只跑 dummy / 非关键层 |
| 稳定期 | 正常派工 |
| 接近下次 PM | 限制高风险层，避免中途打断 |

### 4. 膜厚与应力反馈

| 反馈 | 影响 |
|---|---|
| 厚度偏 | 调整沉积时间或功率，下一批参数变 |
| 均匀性偏 | 可能换腔体或换机台 |
| 应力偏 | 影响翘曲，后续光刻套刻和键合会出问题 |

**应力这条最容易被漏。** 它不在 TF 区暴露，在光刻和封装区爆出来，归因很难。

### 5. 前后接续

| 位置 | 约束 |
|---|---|
| TF 前 | 前一层是否完成、表面是否清洁、有无 native oxide |
| TF 后 | 多久内必须进下一道（Q-time），是否必须立刻量测 |
| 特殊层 | 有些膜暴露空气会变质，窗口极短 |

### 6. 温度与批次形态

| 类型 | 形态 | 批量性 |
|---|---|---|
| PVD | 单片 / 小批 | 弱 |
| CVD（单片） | 单片 | 弱 |
| ALD | 单片 / 小批 | 弱 |
| LPCVD（炉管型） | 强批量 | **归 Diffusion 区** |

LPCVD 虽然也是薄膜，但决策对象是组炉，不是腔体，所以归到 [Diffusion](../diffusion/index.md)。这条边界要写清楚，否则会出现两套规则抢同一批机台。

## 典型派工问题

### 问题 1：靶材末期集中跑关键层

| 项 | 内容 |
|---|---|
| 现象 | 关键层膜厚漂移、颗粒超标 |
| 根因 | 靶材只设寿命上限，没有分段 |
| 解法 | 按剩余寿命分段，末期限制关键层 |
| 指标 | target-end critical lot count、膜厚偏差 |

### 问题 2：dedication 配得过死，产能自锁

| 项 | 内容 |
|---|---|
| 现象 | 有腔体空闲，但关键层排队 |
| 根因 | 软性偏好被配成了硬约束 |
| 解法 | 区分硬 dedication 与软偏好，软偏好可被 P1/P2 覆盖 |
| 指标 | dedication blocked count、腔体利用率离散度 |

### 问题 3：PM 后立刻跑关键层

| 项 | 内容 |
|---|---|
| 现象 | PM 后头几片膜厚异常 |
| 根因 | seasoning 没建模，PM 完就当成可用 |
| 解法 | PM 后强制 seasoning 状态，禁止关键层 |
| 指标 | post-PM deviation、seasoning 批占比 |

### 问题 4：应力漂移在下游才暴露

| 项 | 内容 |
|---|---|
| 现象 | 光刻套刻异常、封装翘曲，回头查是 TF 应力偏了 |
| 根因 | 应力不在派工约束里 |
| 解法 | 应力指标进状态，超限腔体降权 |
| 指标 | stress drift、下游套刻异常归因占比 |

## 派工规则骨架

```text
当 TF chamber 预计空闲：
  1. 枚举候选 Lot
  2. 过滤 dedication / qualification / 污染
  3. 检查 chamber 状态：PM、seasoning、matching
  4. 检查靶材/前驱体剩余量与状态段
  5. 检查膜厚/应力反馈是否支持该层
  6. 检查前一道完成状态与后一道 Q-time 窗口
  7. 综合膜厚风险与产能损失选择
```

## 指标体系

| 层级 | 指标 | 用途 |
|---|---|---|
| 主指标 | 有效出片、一次合格率 | 看真实产能 |
| 约束指标 | 膜厚偏差、均匀性、应力漂移、颗粒 | 防止靠冒险提产能 |
| 观测指标 | 靶材剩余分布、seasoning 批占比、dedication blocked | 定位约束来源 |

## 落地路线

1. 先接 chamber 状态：PM、seasoning、matching、dedication。
2. 再接消耗品：靶材、前驱体剩余量，做分段限制。
3. 然后把膜厚反馈接进来，做 feedback freshness。
4. 最后加应力约束和前后接续检查。
5. 回放验证：膜厚偏差、返工率、靶材利用率三条一起看。
