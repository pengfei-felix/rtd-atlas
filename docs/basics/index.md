# 区域工艺基础

这一层是给不熟悉前道工艺的读者补背景的：**九个区在晶圆上到底做了什么**，为什么这些动作会变成派工约束。它是独立于区域分幅的一层底稿，九个区共用同一套工艺解释。

看不懂工艺，后面的约束清单就只是一串名词。看完这页再回各区分幅，「Reticle 为什么会被锁」「炉管为什么要组炉」「Bath 为什么也会退化」这些就有物理依据了。

    每节目前只放一句定位和后续要补的清单。设备形态、典型 recipe、关键参数、与派工的直接关联，后续逐节补。

| 区域 | 在晶圆上做什么 | 一句话难点 |
|---|---|---|
| [Litho 光刻](#litho) | 把图形从 Reticle 印到光刻胶上 | 精度，纳米级套刻 |
| [Etch 刻蚀](#etch) | 把没被保护的薄膜刻掉，图形落到晶圆上 | 选择比与腔体差异 |
| [Diffusion 扩散](#diffusion) | 高温下氧化、扩散、退火、沉积薄膜 | 批量一致性与升降温 |
| [Implant 注入](#implant) | 把杂质离子打进硅里，改电学性质 | 换气换能量的 setup 代价 |
| [TF 薄膜](#tf) | 在晶圆上长金属或介质膜 | 厚度、均匀性、应力三约束 |
| [CMP 研磨](#cmp) | 把表面磨平，给下一层光刻留平坦面 | 磨多了磨少了都要回补 |
| [Clean / Wet 清洗](#clean) | 去掉颗粒、金属、有机残留和自然氧化层 | 药液退化 + Q-time 起点 |
| [Metrology 量测](#metrology) | 测厚度、线宽、套刻、缺陷 | 产能小、recipe 差 30 倍 |

## Litho 光刻 {#litho}

**做什么。** 涂胶 → 曝光 → 显影，一轮下来把 Reticle 上的图形转印到晶圆表面的光刻胶上。这层胶就是下一道刻蚀或注入的掩膜，图形精度直接决定器件能不能做出来。

**为什么是派工难点。** 图形精度要求纳米级，机台必须和产品、层次、Reticle 精确匹配；一片晶圆要回来十几次到几十次，队列来自全厂。

**待补**：曝光波长与分辨率的关系、Reticle/Pod 的物理形态与搬送要求、层数与重入结构、CD 与 overlay 的量测口径。

对应分幅：[Litho 光刻](../litho/index.md)

## Etch 刻蚀 {#etch}

**做什么。** 用等离子体把没有被光刻胶盖住的薄膜去掉，把胶上的图形真正刻进晶圆。刻蚀不足会短路，刻蚀过度会伤底层。

**为什么是派工难点。** 一台 cluster tool 里几个腔体的状态各不相同——资质、PM 记录、seasoning 阶段——派工对象其实是腔体，不是机台。

**待补**：干法与湿法的分工、RIE/ICP 的差异、终点检测原理、选择比与侧壁形貌的判据、chamber matching 的物理来源。

对应分幅：[Etch 刻蚀](../etch/index.md)

## Diffusion 扩散 {#diffusion}

**做什么。** 在高温炉管里做氧化（长二氧化硅）、扩散（把掺杂推入硅中）、退火（修复晶格、激活杂质）和 LPCVD 薄膜沉积。也有单片的快速热处理（RTP）。

**为什么是派工难点。** 一炉几十到上百片同进同出，炉子一开就是几小时到几十小时；组炉错了，浪费的是整炉的时间，不是一片。

**待补**：炉管与 RTP 的适用分工、温度曲线与温区概念、舟具/石英件的寿命与污染、批内批间均匀性的来源。

对应分幅：[Diffusion 扩散](../diffusion/index.md)

## Implant 注入 {#implant}

**做什么。** 把硼、磷、砷等离子加速到一定能量，直接打进硅片表面，改变导电类型和电阻率——阱、源漏、阈值调整都靠它。

**为什么是派工难点。** 换气体、换能量、换剂量都要重新整定束流，单次 setup 可能比一批的加工时间还长，所以优化的重点从「减少空转」变成「减少切换」。

**待补**：剂量/能量/角度三个参数各自的物理含义、束流整定为什么慢、高能力机与污染隔离的由来、注入后退火窗口为什么紧。

对应分幅：[Implant 离子注入](../implant/index.md)

## TF 薄膜 {#tf}

**做什么。** 用 PVD（溅射）、CVD（化学气相沉积）、ALD（原子层沉积）在晶圆表面长一层金属或介质膜。导电层、阻挡层、绝缘层、硬掩膜都从这里来。和刻蚀正好相反：刻蚀是减材，薄膜是增材。

**为什么是派工难点。** 一台 cluster tool 里各腔体的靶材年龄、前驱体余量、matching 分组都不同，派工对象是腔体不是机台；而且靶材是消耗型资源，末期会直接影响膜厚和颗粒，不能说"还没用完就能用"。

**待补**：PVD/CVD/ALD 的适用分工与温度上限、靶材寿命的计量方式（kWh vs 片数）、膜应力怎么产生又怎么影响下游、LPCVD 为什么归扩散区。

对应分幅：[TF 薄膜](../tf/index.md)

## CMP 研磨 {#cmp}

**做什么。** 旋转的研磨垫压着晶圆，配合含磨料的浆料，把表面凸起的介质或金属磨掉，给下一层光刻留一个全局平坦的表面。没有它，多层堆叠后焦点就压不住了。

**为什么是派工难点。** 研磨垫是连续退化资源，磨得好不好要看量测结果，下一批的参数得跟着改——这是全厂唯一「上一批决定下一批」的区，派工和工艺控制绑在一起。

**待补**：pad 与 slurry 的作用机理、dishing/erosion 的区别、终点检测与量测链路、run-to-run 控制回路为什么必须和派工一起算。

对应分幅：[CMP 研磨](../cmp/index.md)

## Clean / Wet 清洗 {#clean}

**做什么。** 用酸碱药液、超纯水、有机溶剂把晶圆表面的颗粒、金属离子、有机残留和自然氧化层去掉。几乎每一步关键工序前后都要洗一次——它是全厂出现频次最高的工序。

**为什么是派工难点。** 两件事：一是药液槽（bath）和研磨垫一样是连续退化资源，跑得越多能力越差；二是清洗完成的那一刻，晶圆表面从"受控"变成"暴露"，Q-time 走廊的倒计时就从这里开始。全厂大部分走廊的起点在清洗区。

**待补**：SPM / SC1 / SC2 / DHF 各自的去除对象、批式槽与单片的差异、native oxide 的生长速率、干燥方式（旋转/IPA/Marangoni）的能力边界。

对应分幅：[Clean / Wet 清洗](../clean/index.md)

## Metrology 量测 {#metrology}

**做什么。** 测膜厚、线宽（CD）、套刻精度、缺陷密度。它不改变晶圆，只读取状态——但没有它，前面的工序不知道自己做得对不对，后面的工序不知道该用什么参数。

**为什么是派工难点。** 它有两个身份：占用机台产能的"消费者"，和给其他区提供数据的"生产者"。只按前者排，量测会被当成收尾工序排在最后；按后者排，才会知道有些量测比生产还急——CMP 等着它的结果才能定下一批参数。

另外，同一台机跑不同 recipe 的时长能差 30 倍（膜厚 3 分钟 vs 缺陷扫描 90 分钟），按片数估产能必然估错。

**待补**：inline 与 offline 的分工、采样规则怎么定、椭偏/XRR/OCD 各自的适用面、缺陷检测的 recipe 为什么这么长、校准与标准片的产能占用。

对应分幅：[Metrology 量测](../metrology/index.md)

## Sorter / Stocker {#sorter}

**做什么。** Sorter 把晶圆从一个载具换到另一个载具（合批、拆批、换 FOUP）；Stocker 是载具的立体仓库，带分区和自动存取。它不加工晶圆，只改变"哪片晶圆在哪个载具里、载具在哪个位置"。

**为什么是派工难点。** 它是全厂唯一决策粒度是"载具"而不是"机台"的地方。FOUP 数量有限且是独占资源——载具不够，机台再空也上不了料，这种假性 idle 在报表上会被误判成设备问题。而且载具带污染等级，放错分区就是交叉污染。

**待补**：FOUP 与 Cassette 的规格差异、Stocker 分区规则、8 寸人工暂存区怎么建模、合批拆批对后续派工自由度的影响。

对应分幅：[Sorter / Stocker](../sorter/index.md)
