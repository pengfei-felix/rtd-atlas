# Clean / Wet 清洗区派工档案

**清洗区不产出任何东西，但它决定了全厂一半的 Q-time 起点。** 晶圆出槽那一刻，走廊的倒计时就开始走；清洗区排得慢一点，后面三四个区全部被动。 <span class="badge badge--wip">0.1</span>

## 1 工艺与工序流

### 工艺内容

用酸碱药液、超纯水、有机溶剂去掉晶圆表面的颗粒、金属离子、有机残留和自然氧化层。几乎每道关键工序前后都要洗一次，是全厂出现频次最高的工序。

两件事让它难派：一是药液槽（bath）和研磨垫一样是连续退化资源，跑得越多能力越差；二是清洗完成那一刻，晶圆表面从"受控"变成"暴露"，全厂大部分 Q-time 从这里起算。8 寸以批式槽为主（整篮进出），12 寸大量单片（顺序流转），两种逻辑不能混。

- **装篮 / 装载**：整篮或单片进槽，篮具本身也带污染等级。
- **药液槽**：SPM、SC1、SC2、DHF 按去除对象选，槽液按片数或时间累积消耗。
- **中间漂洗**：隔开两道药液，防交叉反应。
- **第二药液槽**：常见两段式（如 SPM 去有机 + DHF 去氧化层）。
- **最终漂洗**：超纯水去残液，水质与流量直接影响颗粒。
- **干燥**：旋转、IPA 或 Marangoni，方式不同，能力边界也不同。

### 派工特点

| 特点 | 落在哪一步 | 不管会怎样 |
|---|---|---|
| **Bath 寿命** | 药液槽 | 末期能力下降，片子洗不干净，而且当场看不出来，要等量测或缺陷检测才暴露 |
| **换液停机** | 药液槽 | 换液是整段缺失，不是效率下降——那段时间产能为零，排队直接积压 |
| **走廊起点** | 干燥出槽 | 出槽即计时，排得慢一点，后面三四个区的余量全被吃掉 |
| **批式合流** | 装篮 / 装载 | 装不满强行等批，走廊断掉；装不满就走，槽体利用率又亏 |
| **酸碱与金属隔离** | 全程 | 配错槽就是整线金属污染事故，停机清洗的代价远超一次排错 |
| **出口限流** | 干燥 → 下游 | 洗得太快下游接不住，WIP 全堆在走廊上，反而把 Q-time 等爆 |

### 上下游

- **上游**：几乎每个区的后道——刻蚀后、注入后、CMP 后、成膜前都要洗。
- **下游**：光刻（上胶前）、扩散（进炉前）、量测。
- **横切**：与 Diffusion 共享 WET-DIFF 双窗——组批动作发生在 WET，但何时开批由炉台状态决定。

## 2 专有派工功能

5 项，按影响程度排：先可行性（约束），再效率（策略），最后协调（接口）。这个区的规则几乎全围着**槽体**和**合流**。

| 功能 | 类型 | 功能描述 | 解决什么问题 |
|---|---|---|---|
| Wet Recipe 组合派活 | 约束 | 部分 WET 机台需考虑酸槽 / recipe 组合，判断上一批 recipe 并按组合比例派货 | 对应「酸碱与金属隔离」：槽位配错，交叉污染，整段停机 |
| Wet Form Batch | 策略 | 检查 wet 机台的 form batch 最大最小片数，把能凑一槽的 Lot 一起上机 | 对应「批式合流」：不凑批，槽体空跑，利用率与走廊两头亏 |
| WET Batch Lot 连续派工 | 策略 | 依 WET-DIFF 预组批结果，同一 batch 内的 Lot 连续派货 | 对应「走廊起点」：批内 Lot 分批出槽，先出的那批在走廊里干等 |
| WET 瓶颈 Tank | 策略 | WET 排程时考虑瓶颈 Tank，保证瓶颈槽体不 idle | 对应「换液停机」：瓶颈槽空着，整段流程跟着停 |
| GOI Lot | 接口 | 支持 GOI lot 自动派工，支持 furnace 单跑 fml 做测机 | 对应「出口限流」：测机批要按期出，系统不认就永远排在最后 |
