# Clean / Wet 清洗区派工档案

<div class="keyline" markdown>

**清洗区不产出任何东西，但它决定了全厂一半的 Q-time 起点。** 一片晶圆离开清洗槽的那一刻，走廊的倒计时就开始走了——清洗区排得慢一点，后面三四个区全部被动。

</div>

## 核心结论

1. **bath 是退化型资源，和 CMP 的 pad 同类。** 药液按处理片数或时间累积消耗，末期能力下降，不是可用/不可用。
2. **清洗是 Q-time 走廊的最大起点。** 走廊从哪里算起，取决于清洗在工艺路线中的位置，通用层要按事件计时，不按固定时刻。
3. **批式和单片是两套逻辑。** 8 寸以批式槽为主，12 寸大量单片；批式要合流，单片讲顺序。
4. **酸碱与金属污染是硬隔离。** 这一层配错的后果是整条线的金属污染事故。
5. **清洗机数量少但被所有区依赖。** 它自己不一定是瓶颈，却能让所有区一起堵。

<div class="rtd-strip" markdown>

<span>决策粒度</span> 批式：Batch → Bath；单片：Lot → Tool  
<span>核心矛盾</span> bath 寿命 vs 走廊起点 vs 污染隔离

</div>

## 与其他区的结构差异

| 维度 | CMP | Clean / Wet | 差异要点 |
|---|---|---|---|
| 退化资源 | Pad（机械磨损） | **Bath（化学消耗）** | 两者都是连续退化，但 bath 换液是整槽换 |
| 批量性 | 单片 | **批式 + 单片并存** | 8 寸批式为主，12 寸单片为主 |
| 加工目标 | 去除厚度 | **去除污染** | 不改变尺寸，只改表面状态 |
| 失败模式 | 厚度偏差 | **残留 / 腐蚀 / 交叉污染** | 多数在下一道或量测才暴露 |
| 在走廊中的角色 | 中段 | **最常见起点** | 计时起点集中在这里 |

清洗的特殊性在于：**它是唯一一个"不做对任何尺寸、但做错毁全厂"的区。** 派工优化如果只按吞吐算，会系统性地低估它的重要性。

## 七类约束结构

### 1. Bath 寿命

| 类型 | 计量 | 处理 |
|---|---|---|
| 药液槽（SPM、SC1、SC2、DHF） | 处理片数 / 累计时间 / 浓度 | 分段限制，末期只跑非关键层 |
| 循环过滤系统 | 颗粒计数 | 超限触发换液 |
| 超纯水 / 干燥剂（IPA） | 水质、含水量 | 水位与品质双判 |

bath 的退化比 pad 更难观测——pad 有厚度和粗糙度可测，bath 只能靠片数累计加定期抽检。**这意味着状态可信度更低，派工要留更保守的余量。**

### 2. 批式与单片

| 形态 | 典型尺寸 | 决策粒度 | 核心问题 |
|---|---|---|---|
| 批式槽 | 8 寸为主 | Batch → Bath | **合流**：哪些 Lot 能拼一槽 |
| 单片 | 12 寸为主 | Lot → Tool | **顺序**：先洗谁，bath 什么时候到点 |
| 混合 | 部分 12 寸 | 两者并存 | 两套逻辑要能共存 |

批式槽的合流问题和扩散区的组炉同源，但更宽松：清洗对"同槽批次一致性"的要求低于炉管，允许更多混批——前提是化学品体系相同。

### 3. 污染隔离

| 隔离维度 | 例子 | 强度 |
|---|---|---|
| 酸碱分离 | SPM / DHF 与 SC1 | 硬 |
| 金属离子 | 含金属污染片单独处理 | 硬 |
| 有机 / 无机 | 去胶与清洗分开 | 硬 |
| 前段 / 后段 | 金属层之后不能回前段槽 | 硬 |
| 产品族 | 某些产品专用槽 | 视情况 |

隔离维度多，且**都是硬约束**。清洗区的规则里，过滤类规则占比远高于排序类规则，这是它和 Litho / Etch 的显著差异。

### 4. Q-time 起点

清洗之后通常接：

| 后道 | 窗口特点 |
|---|---|
| 光刻（含 HMDS 前烘） | 短，最为关键 |
| 氧化 / 沉积 | 需防 native oxide 再生，窗口极短 |
| 量测 | 窗口宽松 |
| 刻蚀 | 中等 |

**native oxide 这条最紧。** 清洗完的裸硅暴露在空气中，氧化层按分钟级增长，所以"清洗 → 沉积"这一段经常是最短的窗口。

### 5. 干燥方式

| 方式 | 适用 | 派工影响 |
|---|---|---|
| Spin dry | 单片 | 占用机台时间，影响节拍 |
| IPA 气相干燥 | 批式 | 需 IPA 供应与品质 |
| Marangoni | 高深宽比结构 | 能力稀缺，关键层专用 |

干燥能力不够时，会出现"洗完不能出"的情况——这比洗不了更糟，因为 Lot 卡在中间，走廊已经开始计时。

### 6. 水质与供应

超纯水的水质（电阻率、TOC、颗粒）是隐性约束。水质波动时，即使机台可用，也不该跑关键层。

### 7. 重洗回路

清洗不合格可以重洗，代价比 TF 返工低得多，但要注意：

| 风险 | 说明 |
|---|---|
| 重复清洗损伤 | 多次 SPM 会消耗掉部分膜层 |
| 计数上限 | 重洗次数要设上限 |
| 污染扩散 | 重洗批可能把污染带进槽体 |

重洗是清洗区相对"幸运"的地方——它是少数几个返工代价可接受的区。

## 典型派工问题

### 问题 1：bath 末期跑关键层

| 项 | 内容 |
|---|---|
| 现象 | 颗粒或残留超标，集中出现在换液前 |
| 根因 | bath 只设片数上限，没有分段 |
| 解法 | 按状态段限制关键层，末期只跑非关键 |
| 指标 | bath-end defect count、换液前不良率 |

### 问题 2：批式槽合流把走廊挤爆

| 项 | 内容 |
|---|---|
| 现象 | 为了装满一槽，让急件等慢件 |
| 根因 | 合流只优化装载率，不看下游窗口 |
| 解法 | 合流时把走廊余量当约束，不足则允许欠载 |
| 指标 | batch wait time、因等批导致的走廊 breach |

### 问题 3：清洗快，但下游接不住

| 项 | 内容 |
|---|---|
| 现象 | 清洗区利用率高，Lot 堆在清洗出口 |
| 根因 | 清洗不检查后道可接续性 |
| 解法 | 出口限流，按后道产能放行 |
| 指标 | clean-out wait、后道饥饿与拥堵 |

### 问题 4：干燥能力成为隐藏瓶颈

| 项 | 内容 |
|---|---|
| 现象 | 洗完出不来，或被迫换低能力干燥方式 |
| 根因 | 干燥不作为独立资源建模 |
| 解法 | 干燥能力进资源视图，关键层锁定高能力干燥 |
| 指标 | dry wait、Marangoni 占用率 |

## 派工规则骨架

```text
当 clean tool / bath 预计可用：
  1. 枚举候选 Lot
  2. 过滤污染隔离（酸碱/金属/前后段）—— 硬约束，优先级最高
  3. 检查 bath 状态段，末期限制关键层
  4. 批式：判断可合流的候选集，评估装载率 vs 走廊余量
     单片：按走廊余量排序
  5. 检查后道：出口能不能接、干燥能力够不够
  6. 检查是否已进入某条走廊，剩余预算多少
  7. 选择"不让任何走廊 breach"的最优组合
```

第 7 步的措辞是有意的：**清洗区的目标不是自己利用率最高，是不让下游的走廊超时。** 这两个目标在多数时候一致，在批式合流时经常冲突。

## 指标体系

| 层级 | 指标 | 用途 |
|---|---|---|
| 主指标 | 有效出片、走廊起点准时率 | 看它对全厂的真实贡献 |
| 约束指标 | bath 末期不良、交叉污染事件、重洗率 | 防止靠冒险提产能 |
| 观测指标 | bath age 分布、合流装载率、dry wait、clean-out wait | 定位约束来源 |

## 落地路线

1. **先做污染隔离**：这是纯过滤规则，收益最直接，也最能挡住事故。
2. **再接 bath 状态**：从机台日志累计片数，做分段限制。
3. **然后做出口限流**：这是 Q-time 走廊能成立的前提。
4. **最后做合流优化**：批式槽的组批，把走廊余量作为约束。
5. 回放验证：走廊 breach 率、bath 末期不良、装载率三条一起看。
