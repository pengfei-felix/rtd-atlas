# 搬送优先级冲突

<div class="keyline" markdown>

**搬送优先级不能简单等于 Lot 优先级。** Hot Lot、瓶颈供料、Q-time、port 释放、Reticle pod 同步，都会争夺同一套 OHT 能力。

</div>

## 冲突类型

| 冲突 | 正确判断 |
|---|---|
| Hot Lot vs 瓶颈供料 | 瓶颈即将饥饿时，供料可能优先 |
| 入站 vs 出站 | output port 堵塞时，出站优先 |
| Lot vs Reticle pod | 双资源同步，缺一不可 |
| Q-time red vs 普通搬送 | red 优先，但记录影响面 |
| 预搬送 vs 当前执行 | 预搬送不能打穿当前必要搬送 |

## 搬送 score

```text
move_score = qtime_urgency
           + bottleneck_starvation_risk
           + port_blockage_risk
           + resource_sync_need
           - wasted_move_risk
```

## 指标

- OHT priority override；
- bottleneck starvation due to transport；
- output port blockage；
- reticle-lot sync miss；
- wasted high-priority move。

## 避坑

| 坑 | 后果 |
|---|---|
| Hot Lot 全部最高搬送优先级 | 搬送系统被打穿 |
| 只搬 Lot 不搬辅助资源 | 到机台也开不了工 |
| 不释放过期预搬 | stocker 被无效 WIP 占满 |
| output move 优先级低 | 设备无法出片，形成假忙 |
