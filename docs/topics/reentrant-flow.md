# 重入流路径

<div class="keyline" markdown>

**同一片晶圆要返回光刻区 18~40 次。** 这意味着队列里同时躺着"第 3 层"和"第 27 层"的 Lot，它们看起来一样，但在流程中的位置完全不同。派工系统如果只看队列长度和优先级，就会反复犯同一个错。

</div>

## 重入的三种形态

| 形态 | 描述 | 例子 |
|---|---|---|
| **同区重入** | 返回同一个工序区，不同层 | 光刻区 18~40 次 |
| **跨区循环** | 在几个区之间来回 | 光刻 → 刻蚀 → 光刻 → 离子注入 |
| **全流程环路** | 一整条工艺循环 | 前道 → 后道 → 再回前道（先进封装） |

三种形态的派工含义不同：同区重入影响**队列构成**，跨区循环影响**时间窗串联**，全流程环路影响**在制品总量**。

## 后果一：队列构成不断变化

光刻区的队列里，Lot 来自所有层、所有产品、所有优先级。**这个构成每十几分钟就换一副面孔。**

这带来一个直接问题：

> 任何只看"当前队列"的派工规则都会失真。

比如"同 Recipe 优先"——十分钟前队列里同 Recipe 的 Lot 很多，一条规则很有效；十分钟后它们被清空，同一条规则变成了噪声。

**所以规则要在更长的时间尺度上评估效果**，不能用一个瞬时快照来调参数。

## 后果二：层间有严格时序依赖

第 N 层的 Lot 没做完，第 N+1 层就没办法开工。而它们在同一台机上竞争。

```
Lot A：层 5 → 层 6 → 层 7     ← 正在层 6
Lot B：层 5 → 层 6 → 层 7     ← 已到层 7，等着上机
Lot C：层 5 → 层 6 → 层 7     ← 刚到层 5
```

三批看起来都是"光刻区的一个 Lot"，但 A 卡在中间、B 快完了、C 刚开始。**只看到期时间会把 C 排在 B 前面**，结果是 B 在窗口边缘等着，整条链的节拍被打乱。

## 后果三：瓶颈被重入放大

重入次数是**线性放大负荷**的。产品层数从 20 层升到 35 层，光刻区的总负荷增加 75%——但设备台数没变。

所以：

!!! warning "换产品组合 = 换瓶颈"
    层数高的产品占比一升，光刻区负荷立刻上去。昨天还不是瓶颈的区，今天可能就是。这也是 [瓶颈判定](../overview/bottleneck.md) 要求按滚动窗口算、不能按季度算的原因。

## 派工上的三个应对

### ① 带状态

派工决策要能看到 Lot 的**路径历史**：它做过几层、上一次在本区是什么时候、下一层什么时候该到。

无状态的派工系统每次从零算，等于把重入结构的价值全丢了。

### ② 看回流预测

不要只问"现在队列里有什么"，要问"**未来 30 分钟会有谁回来**"。

光刻区 80% 的白空间不是产能不足，是"料到了罩没到"。反过来也成立：如果知道下一批马上回来，可以提前把罩搬过来。

### ③ 层间配平

在同一台机上，不同层的 Lot 应该有**合理的进入节奏**，而不是谁先到谁先上。

目标是让每一层的下游都不缺料——这是"喂饱下游"，不是"清空当前队列"。

## 一个反直觉的结论

**队列越短不一定越好。** 重入结构下，光刻区需要有足够的在制品来保证"任何时候都有合适的层可做"。队列被压到过低，机台会因为"没有匹配的层"而空转——这时候提高投料反而提升产出。

这个平衡点因厂而异，但判断方法一致：**看白空间的构成**。如果白空间主要是"没有可加工对象"，就是投料不足；如果是"料到了罩没到"，就是辅助资源问题。
