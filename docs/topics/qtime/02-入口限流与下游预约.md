# Q-time 入口限流与下游预约

## 入口限流

Q-time 风险很多不是处理慢造成的，而是入口放太多造成的。

| 限流对象 | 说明 |
|---|---|
| 当前窗口入口 | 控制进入危险窗口的 Lot 数 |
| 下游瓶颈入口 | 避免下游接不住 |
| AMHS 搬送入口 | 避免黄区 Lot 全部压到搬送系统 |
| 批加工入口 | 避免 batch tool 组不起来 |

## 走廊容量

```text
corridor_capacity = min(process_capacity, downstream_capacity, AMHS_capacity, resource_capacity)
```

单点能力高没有意义。走廊容量由最弱环决定。

## 下游预约

| 预约对象 | 用途 |
|---|---|
| tool / chamber | 确认下一工步可接 |
| port / stocker | 确认可到位 |
| auxiliary resource | Reticle / Boat / Pad 同步 |
| AMHS move | 控制搬送长尾 |

预约必须有有效期。过期不释放，会变成资源锁死。

## 策略

```text
if corridor_load > cap:
    stop_releasing_new_lots()
if lot_state == YELLOW:
    reserve_downstream()
if downstream_reservation_failed:
    avoid_track_in_upstream()
```

## 指标

- corridor load；
- yellow-zone dwell；
- reservation hit rate；
- release blocked by cap；
- Q-time transport loss；
- expired reservation count。
