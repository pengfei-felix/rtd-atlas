# Q-time 违规归因与回放

<div class="keyline" markdown>

**Q-time 违规不能只记“哪个 Lot 超时”。** 专业复盘要问：超时是投料造成的、设备造成的、搬送造成的、派工造成的，还是下游预约失败造成的。

</div>

## 归因分类

| 分类 | 判断依据 |
|---|---|
| Release overload | 窗口入口放入 Lot 超过走廊容量 |
| Tool capacity | 目标设备 / chamber 不足或 PM |
| Resource missing | Reticle / Boat / Pad 未到位 |
| AMHS delay | ETA 长尾或 stocker/port 堵塞 |
| Dispatch priority | 系统选择了低风险 Lot，饿死高风险 Lot |
| Downstream blocked | 上游完成后下游不可接 |
| Engineering hold | 工程 hold / 质量限制 |

## 回放问题

每次违规至少回放三个时间点：

| 时间点 | 要看什么 |
|---|---|
| 进入窗口时 | 当时走廊容量是否足够 |
| 进入 yellow 时 | 系统是否触发预约 / 预搬送 |
| 进入 red 时 | 是否还有可行选择 |

## 复盘模板

```text
违规 Lot：Lxxxx
窗口：Clean → Etch
进入窗口：10:20
进入 Yellow：11:40
进入 Red：12:55
违规时间：13:25
主因：AMHS_DELAY
次因：DOWNSTREAM_RESERVATION_MISS
纠正：yellow 阶段提前 pre-position，reservation valid_until 从 20 min 调整为 35 min
```

## 指标

- violation by reason code；
- yellow action missing rate；
- red rescue success rate；
- root cause aging；
- repeat violation pattern。
