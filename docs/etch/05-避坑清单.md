# Etch 避坑清单

| 坑 | 后果 | 正确做法 |
|---|---|---|
| 只做 tool 级派工 | chamber 空闲和排队并存 | 展开到 Lot-Chamber pair |
| EAP available 等于可派 | PM 后关键批漂移 | dispatch_state 独立建模 |
| matching group 永久写死 | 少数 chamber 被压死 | matching 分层 + 定期复核 |
| 污染规则写成权重 | 高分目标冲掉质量边界 | 污染规则硬过滤 |
| campaign 不设边界 | Q-time / Hot Lot 被饿死 | max run + break condition |
| rework 当普通 Lot | 返工冲击正常产能 | rework 单独候选池和能力预留 |
| 不看下游 | Etch out 后堵住 | track-in 前检查 strip/clean/metrology |
| 不记录过滤原因 | 规则过严没人知道 | dispatch log 保留 candidate/filter |

## 最小上线检查

1. chamber qualification 是否系统化；
2. post-PM / seasoning 是否进 RTD；
3. from-to setup 矩阵是否可用；
4. contamination rule 是否硬过滤；
5. rework 是否有 reason code；
6. downstream reservation 是否参与高风险派工；
7. chamber 级指标是否能按班次统计。
