## 与 Litho 的结构差异（先定性）

派工的决策粒度从「机台」下沉到 **chamber**。一台 cluster tool 有多个 chamber，各自有独立的资质状态、PM 记录和 seasoning 阶段。所以 Etch 的派工本质是 `Lot → chamber`，而不是 `Lot → tool`。

另一个差异是**辅助资源不是光罩，而是腔体本身的状态**。Reticle 有唯一性和搬运时间；Chamber 有资质、清洁周期和匹配度。

## 预期约束清单

| 约束 | 本区表现 | 待你核实 |
|---|---|---|
| 颗粒度 | chamber 级排产，非 tool 级 | 贵厂 RTD 是否已下沉到 chamber |
| 机台专属性 | 关键层固定 chamber，控制 CD 一致性 | 哪些层 locked |
| Chamber matching | 同型号不同 chamber 存在速率差，不能当等效并行机 | 速率分布范围 |
| PM 与 seasoning | PM 后需跑 seasoning wafer 恢复，期间产能打折 | seasoning 片数与耗时 |
| 序列相关整定 | 换 Recipe 需气体切换、RF 稳定、chamber clean | 典型换线时间 |
| Q-time | 刻蚀后到 PR strip / 下一工序的时间窗，超时可能腐蚀 | 管控粒度 Lot 级还是 Wafer 级 |
| 量测回路 | CD / 深度量测触发 OOC → 重工回原 chamber | 重工率 |
| 气体供应 | 特种气体库存与切换可能成为隐性约束 | 是否进过 RTD 模型 |
