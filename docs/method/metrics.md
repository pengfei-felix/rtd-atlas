# 指标体系

## 指标会互相拆台

这是派工项目最容易翻车的地方：**没有单一指标能代表「派工变好了」**。

- 提吞吐 → 可能在制品（WIP）堆积、周期时间（CT）变长
- 压 CT → 可能牺牲机台利用率，白空间增加
- 提利用率 → 可能增加换线次数，Reticle / Pad 搬运量飙升

所以指标体系必须先定**主指标**，再定**约束指标**（不能恶化的红线），最后才是**观测指标**（用来诊断，不用于考核）。

## 三层结构

| 层 | 作用 | 典型指标 |
|---|---|---|
| 主指标 | 项目验收的唯一判据 | 吞吐量、产出片数 |
| 约束指标 | 不允许恶化的红线 | 周期时间、Q-time 违规率、搬运次数 |
| 观测指标 | 定位问题 | 机台利用率、白空间占比、队列长度、换线次数、批装载率 |

## 日常监控

派工系统的日常监控和项目验收不是同一套数。验收看「相对基线的改善」，日常看「有没有异常漂移」。前者需要对照组和足够长的窗口，后者看的是趋势和阈值告警。

!!! warning "关于引用数字"
    公开文献里的改善幅度（利用率 +1%~2%、吞吐 +2%~9.4%、Reticle Move −5%、Q-time −4%）横跨 2011–2025 年、不同基线、不同厂型。**只能当量级参考**。合同里要写的是「在贵厂基线上实测改善 X%」的验证方法和对赌条款，不是这些数字本身。
