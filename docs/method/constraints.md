# 约束模型

## 四类资源

任何区的派工约束，最终都能归到这四类里。归类错了，模型就会漏资源。

| 类别 | 定义 | 典型例子 |
|---|---|---|
| **主资源** | 执行加工的设备或设备子单元 | 机台、chamber、platen |
| **辅助资源** | 加工必需但不能同时被两处使用的东西 | Reticle / Pod、Pad、舟具、专用气体 |
| **时间窗资源** | 只能在某个时间区间内消耗的机会 | Q-time 前后窗、hold time |
| **人力/物料** | 受班次、库存限制的投入 | 工程师支持、靶材、slurry |

## 两类建模错误

**1. 把连续量建成布尔量。** Reticle 不是「有/没有」，而是带位置、容量、搬运时延和寿命的受限资源；Pad 不是「好/坏」，而是连续退化状态。布尔化会让优化器排出物理上做不到的计划。

**2. 把辅助资源留在模型外。** 只对主资源建模，辅助资源靠现场临时调度——这是白空间（机台空转）最常见的来源。Litho 的「料到了罩没到」就是典型后果。

## 目标函数

派工的目标函数不是单一指标，通常是加权组合：

```
score(lot, tool) = w1·紧迫度 + w2·换线代价⁻¹ + w3·Q-time 余量 + w4·利用率贡献 + ...
```

权重的定法比公式本身重要。见 [指标体系](metrics.md)。
