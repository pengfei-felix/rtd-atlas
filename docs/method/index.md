| 章节 | 解决什么问题 |
|---|---|
| [约束模型](constraints.md) | 把一个区的现场约束翻译成可计算的资源集合与目标函数 |
| [规则库设计](rule-library.md) | 规则越加越多、互相打架，怎么控制 |
| [RTS 与 RTD 分层](rts-rtd.md) | 调度和派工谁听谁的，阈值设在哪里 |
| [指标体系](metrics.md) | 验收看什么数，日常盯什么数，怎么避免指标互相拆台 |
