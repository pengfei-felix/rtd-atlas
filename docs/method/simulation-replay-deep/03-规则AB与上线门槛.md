# 规则 A/B 与上线门槛

## A/B 对比对象

| 对比 | 说明 |
|---|---|
| historical actual | 历史人工 / 旧系统实际执行 |
| old rule replay | 旧规则在同一事件流下的推荐 |
| new rule replay | 新规则推荐 |
| shadow recommendation | 在线影子推荐 |

## 指标包

不能只看 throughput。上线指标至少包括：

- effective throughput；
- cycle time by priority；
- Q-time yellow / red / violation；
- setup / clean / tune loss；
- AMHS transport loss；
- override rate；
- normal lot displacement；
- quality inhibit hit。

## 上线门槛模板

| 门槛 | 要求 |
|---|---|
| 硬约束 | 0 容忍违规 |
| Q-time | violation 不增加，red dwell 下降 |
| 普通批影响 | normal CT 不得显著恶化 |
| Hot Lot | 改善要说明代价来源 |
| 解释性 | 95% 推荐有标准 reason code |
| 回退 | solver / 数据异常时自动 fallback |

## 灰度路径

```text
历史回放
  → shadow mode
  → 非关键层建议模式
  → 局部自动执行
  → 扩区域执行
  → 周期性回放复盘
```

## 结论写法

专业结论不要写“新规则提升明显”，而要写：

> 新规则将 Q-time red dwell 降低 18%，代价是 setup loss 增加 3.2%。普通批 P80 CT 未显著恶化，Hot Lot 等待下降主要来自提前 pre-position，而不是靠强插队获得。建议先在 ETCH_GRP_01 非关键层灰度。
