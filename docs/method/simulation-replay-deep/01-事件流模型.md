# 仿真回放事件流模型

<div class="keyline" markdown>

**回放不是拿历史结果做报表，而是按当时可见的信息重建现场。** 任何未来信息提前进入回放，都会让规则看起来虚假变好。

</div>

## 最小事件集

| 事件 | 作用 |
|---|---|
| lot_arrive | 候选集进入 |
| track_in / track_out | 加工开始和结束 |
| tool_state_change | 设备可用性变化 |
| chamber_state_change | chamber 级状态变化 |
| resource_move | 辅助资源 / FOUP 搬送 |
| hold_release | 工程 hold 与 release |
| metrology_result | 反馈可见时间 |
| dispatch_decision | 历史实际派工 |

## 时间原则

| 原则 | 说明 |
|---|---|
| event time | 事件真实发生时间 |
| visible time | 系统可见时间 |
| replay time | 回放推进时间 |

回放必须使用 visible time。量测结果 13:00 才可见，就不能在 12:30 的派工中使用。

## 状态快照

每次派工点都应保存：

- Lot queue；
- Tool/chamber state；
- Resource state；
- AMHS ETA；
- Q-time state；
- active rule version；
- APS/RTS plan version。
