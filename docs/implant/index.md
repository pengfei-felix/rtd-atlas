## 与 Litho 的结构差异（先定性）

**换靶/换气的 setup 成本在本区占主导地位。** 一台注入机的能量、剂量、离子种类切换都是一次长整定，单次 setup 时间甚至可能超过一批的加工时间。所以派工的优化目标从「减少空转」变成「**减少换线次数**」——宁可等一等凑批，也不要频繁切换。

| 约束 | 本区表现 | 待你核实 |
