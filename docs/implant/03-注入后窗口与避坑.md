# Implant 注入后窗口与避坑

## 注入后窗口

Implant 完成后常接 anneal、strip、clean 或 metrology。若下游不可接，注入端准时完成也没有意义。

| 接续 | 风险 |
|---|---|
| Anneal | 等待过长影响修复和激活窗口 |
| Strip / Clean | resist / contamination 风险 |
| Metrology | 反馈滞后，影响后续 recipe |
| AMHS move | 长距离搬送吃掉窗口余量 |

## 派工前检查

```text
projected_implant_out
  → downstream availability
  → AMHS ETA
  → qtime remaining after move
  → reservation feasible?
```

若无法预约下游，RTD 不应盲目 track-in。

## 避坑清单

| 坑 | 后果 | 修正 |
|---|---|---|
| 只按 recipe 排序 | tune 时间暴涨 | setup family + from-to matrix |
| 污染规则做成权重 | 质量边界被冲掉 | hard filter |
| 高能力机不保护 | 稀缺能力被普通任务吃掉 | scarcity index |
| 确认片不扣产能 | APS 产能乐观 | confirmation event 入模型 |
| 注入后才看下游 | anneal / clean 窗口被动救火 | track-in 前预约下游 |
| Hot Lot 无脑插队 | campaign 崩、普通批 CT 拉长 | impact assessment |

## 上线检查

1. setup matrix 是否覆盖主要 family；
2. contamination rule 是否经过工艺确认；
3. beam tune / confirmation 时间是否进入 effective capacity；
4. high capability tool 是否有保护策略；
5. implant-out downstream reservation 是否可用；
6. 回放是否覆盖 Hot Lot 打断 campaign 场景。
