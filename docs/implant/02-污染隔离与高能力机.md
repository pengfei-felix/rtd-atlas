# Implant 污染隔离与高能力机保护

<div class="keyline" markdown>

**Implant 的硬边界是污染，隐性瓶颈是高能力机。** 污染规则不能被权重冲掉；高能力机不能长期被低要求任务占满。

</div>

## 污染规则

| 类型 | 处理 |
|---|---|
| 专机专用 | 硬过滤 |
| 单向切换 | sequence rule |
| clean 后允许 | 增加 clean + qualification 时间 |
| 禁止混跑 | 同 campaign 中不得混入 |
| 工程临时放开 | 必须有审批和过期时间 |

污染规则应进入 hard filter，而不是 score。

## 高能力机保护

高能力机通常能跑低要求任务，但不应被低要求任务长期占用。

| 字段 | 用途 |
|---|---|
| capability_level | 能量 / 剂量 / species 能力等级 |
| scarcity_index | 替代设备越少，越稀缺 |
| protected_recipe | 需要保护的关键任务 |
| downgrade_allowed | 是否允许跑低要求任务 |
| release_condition | 什么时候允许释放保护 |

## 派工策略

```text
if candidate.requires_scarce_capability:
    prioritize_scarce_tool()
elif candidate.can_run_on_common_tool:
    penalize_using_scarce_tool()
```

## 典型问题

| 问题 | 根因 | 策略 |
|---|---|---|
| 高能量任务排队 | 高能力机被低要求任务占 | 稀缺能力保护分 |
| 人工频繁拦截 | 污染规则未系统化 | hard filter + override log |
| clean 后产能低估 | clean 与 confirmation 未扣产能 | effective capacity 回灌 APS |
| 工程临时放开长期有效 | 例外规则无过期 | exception valid_until |

## 验证指标

- scarce tool occupation by low-requirement lots；
- contamination block count；
- manual override due to contamination；
- clean-triggered capacity loss；
- protected recipe waiting time。
